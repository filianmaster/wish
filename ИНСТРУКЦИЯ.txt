ИСПРАВЛЕНИЕ WISH

В репозитории index.html уже загружает ./src/main.js, а package.json собирает файлы из src/**.
Но в репозитории main.js лежал в корне, поэтому приложение не находило игровой файл.

ЧТО ДЕЛАТЬ:
1. Открой https://github.com/filianmaster/wish
2. Нажми Add file -> Upload files.
3. Распакуй этот архив на компьютере.
4. Перетащи папку src целиком (внутри src лежит main.js) в окно GitHub.
5. Нажми Commit changes в ветку main.
6. Открой Actions и дождись новой сборки WISH — собрать приложение.
7. Скачай новый WISH-Windows из Artifacts и распакуй его.
8. Запусти WISH.exe.

Не удаляй остальные файлы репозитория. Старый main.js в корне можно оставить — новая сборка его не использует.
