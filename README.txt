WISH — ГОТОВЫЙ ПРОЕКТ ДЛЯ GITHUB
=================================

ТЕБЕ НЕ НУЖЕН ТЕРМИНАЛ ИЛИ NODE.JS НА ТВОЁМ ПК.

ЧТО ДЕЛАТЬ:
1. Создай на GitHub новый репозиторий с названием WISH.
2. На странице репозитория нажми Add file → Upload files.
3. Открой распакованную папку WISH-GitHub-Ready.
4. Выдели ВСЁ содержимое папки, включая папку .github, и перетащи в окно загрузки GitHub.
5. Дождись загрузки и нажми Commit changes.
6. Открой вкладку Actions в репозитории.
7. Дождись завершения процесса "WISH — собрать приложение".
8. Открой завершённую сборку (зелёная галочка).
9. Внизу страницы найди Artifacts и скачай WISH-Windows.
10. Распакуй скачанный архив. Внутри будут WISH.exe и ZIP-версия.

ВАЖНО:
- Не загружай сам внешний ZIP как один файл. Нужно распаковать его и загрузить ВСЕ файлы и папки проекта.
- Папка .github скрытая. Проверь, что она тоже загрузилась: в ней лежит инструкция для автоматической сборки.
- Если GitHub спросит подтвердить загрузку, нажми Commit changes.
- После каждого обновления кода GitHub автоматически соберёт новую версию при отправке изменений в main.

ЧТО В ПРОТОТИПЕ:
- 3D-локация «Тихая долина»
- Управление WASD, осмотр мышью, Shift для бега
- Поле желаний
- Создание кваса, цветка, дерева, дома и сундука
- Взаимодействие клавишей E

ОГРАНИЧЕНИЕ ПЕРВОЙ ВЕРСИИ:
Распознавание пока основано на ключевых словах, это не полноценный ИИ. Новые типы желаний будем добавлять постепенно.
