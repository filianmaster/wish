WISH — ПОЛНЫЙ ПРОЕКТ

КАК УСТАНОВИТЬ В GITHUB БЕЗ ТЕРМИНАЛА
1. Открой https://github.com/filianmaster/wish
2. Если хочешь заменить проект целиком, удали старые файлы/папки, которые не входят в этот архив.
3. Нажми Add file → Upload files.
4. Распакуй этот ZIP на компьютере и перетащи ВСЁ содержимое папки WISH-Full-Ready в окно GitHub.
   Важно: загружай именно содержимое, включая папки src и .github, а не сам ZIP.
5. Нажми Commit changes.
6. Открой вкладку Actions. Выбери Build WISH for Windows и нажми Run workflow, если сборка сама не запустилась.
7. Дождись зелёной галочки. Открой завершённый запуск и скачай Artifact WISH-Windows.
8. Распакуй скачанный artifact. Запусти WISH.exe.

ВАЖНО
- Этот workflow намеренно использует npm install, а не npm ci, и не включает кэш npm.
  Поэтому GitHub Actions не требует package-lock.json и не выдаёт прежнюю ошибку про lock-файл.
- Зависимости устанавливаются автоматически на GitHub Actions.
- Для локального запуска на ПК нужны Node.js 22 или новее: npm install, затем npm start.
- Проект рассчитан на Windows x64.
- Это рабочий прототип: 3D-мир, управление WASD/мышью/Shift и несколько распознаваемых типов желаний.
  Свободное понимание любых фраз полноценным ИИ пока не реализовано.
- Если в репозитории остались старые файлы, которые конфликтуют с этим проектом, удали их. Особенно важно не оставлять старые workflow-файлы в .github/workflows.
