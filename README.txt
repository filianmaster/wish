WISH — ПОЛНЫЙ ПРОЕКТ

Загружай ВСЁ содержимое этого архива в корень репозитория https://github.com/filianmaster/wish.
Важно: распакуй архив и загрузи файлы и папки, включая скрытую .github. Не загружай внешний ZIP целиком.

Шаги:
1. Распакуй архив.
2. Открой репозиторий на GitHub.
3. Add file -> Upload files.
4. Выдели всё содержимое распакованной папки (включая .github и src).
5. Commit changes.
6. Открой Actions, дождись Build WISH for Windows.
7. В завершённом запуске скачай Artifacts -> WISH-Windows.
8. Распакуй артефакт и запусти WISH.exe.

Node.js и терминал на твоём компьютере не нужны — сборку выполняет GitHub Actions.

Структура:
index.html
style.css
electron.js
package.json
src/main.js
.github/workflows/build.yml

Three.js импортируется локально из node_modules через import map. Это прототип: мир содержит долину, озеро, деревья, домик; распознаются желания с ключевыми словами для кваса/напитков, цветов, деревьев, домов и сундуков. Это пока не полноценный ИИ для произвольных желаний.
